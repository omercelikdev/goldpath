# UI standard — moved to the kit repo

The family UI standard now lives WITH the kit it governs and versions with the
package: **github.com/qorpe/ui → `docs/ui-standard.md`** (`@qorpe/ui` on npm).

Extraction: RFC [qorpe-ui](../rfc/qorpe-ui.md) (accepted 2026-08-06). The rule that
moved with it: a standard change and the component enforcing it land in the same PR —
enforced there by the kit repo's gates (G1 changeset, G2 docs, G3 axe, G4 visual).

This pointer stays so a decade of links keep resolving; the CONTENT is in the kit repo.
